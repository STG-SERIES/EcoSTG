# EcoSTG 1.5.3

**Jar:** `build/libs/EcoSTG-1.5.3.jar`  
**Requires:** Paper 1.21.11+, Java 21

## What's updated

### Icons
- Dialogs no longer use atlas sprites (those showed as purple/black missing textures on 1.21.11).
- Homes list and home detail now preview the **real item** next to the name.
- **Change Icon** opens a chest GUI of real items (search, default, pages). Click an item to set it.

Existing homes and icons are kept.

## Install

Replace the jar in `plugins/` with `EcoSTG-1.5.3.jar` and **restart**.
