# EcoSTG 1.5.0

**Jar:** `build/libs/EcoSTG-1.5.0.jar`  
**Requires:** Paper 1.21.11+, Java 21

## What's updated

### Homes menu
- Overview shows a bed, your homes, **New Home**, and **Show More** if you have more than two.
- Click a home for **Teleport**, **Change Icon**, **Rename**, and **Delete**.
- **Change Icon** searches the item list (Default = white bed).
- **Rename** uses a text field with Save / Cancel. Names can include spaces (up to 32 characters).

### Existing homes
- This update **does not delete or move homes**.
- It only adds an `icon` column to `homes` (default white bed).
- Old names such as `home1` stay as they are. Players can rename them in the menu if they want.

## Install

Replace the old jar in `plugins/` with `EcoSTG-1.5.0.jar` and **restart** the server. Do not delete `plugins/EcoSTG/ecostg.db`.
