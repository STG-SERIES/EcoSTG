# EcoSTG 1.5.2

**Jar:** `build/libs/EcoSTG-1.5.2.jar`  
**Requires:** Paper 1.21.11+, Java 21

## What's updated

### Icons
- Fixes the purple/black missing-texture icons.
- Block items (wool, wood, fence gates, etc.) now use the **blocks** atlas; tools/items use the **items** atlas (1.21.11 split those textures).

## Install

Replace the jar in `plugins/` with `EcoSTG-1.5.2.jar` and **restart**.
