# EcoSTG 1.5.18

**Jar:** `build/libs/EcoSTG-1.5.18.jar`  
**Requires:** Paper or Purpur 1.21.11+, Java 21

## Changes

- Home detail color control is a real button: ender pearl icon + **Color: …** label.
- New **Set here** button on each home page — moves the home to your current location; keeps name and color.

## Upgrade

Replace the jar with `EcoSTG-1.5.18.jar` and **restart**.
