# EcoSTG 1.5.7

**Jar:** `build/libs/EcoSTG-1.5.7.jar`  
**Requires:** Paper 1.21.11+, Java 21

## What's updated

### Hub
- **Ender Chest** button opens your ender chest from anywhere (`/enderchest`, `/ec`, `/ender`).
- **Sit/lay** submenu when [GSit](https://modrinth.com/plugin/gsit) is installed (Sit, Crawl, Lay, Spin).

### Friends
- Removed the 3D head from friend profiles.
- Removed the **Settings** button from friend profiles (use hub `/settings`).

### Stats
- Removed the 3D head and **View Full Profile** button from stats pages.
- Fixed empty-action dialog crash (`actions cannot be empty`).

### Homes
- Operators can set **unlimited** homes (non-ops still use `homes.max`).

## Install

Replace the jar in `plugins/` with `EcoSTG-1.5.7.jar` and **restart**.
