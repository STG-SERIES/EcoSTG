# EcoSTG 1.5.11

**Jar:** `build/libs/EcoSTG-1.5.11.jar`  
**Requires:** Paper 1.21.11+, Java 21

## What's updated

### Auction House
- Removed **List on Auction** (custom price). The emerald button now opens **`/sell`** (worth.yml prices).
- `/ah <search>` / `/shop <search>` filters listings (material name, pretty name, custom name, or seller). Example: `/ah dirt`.

## Install

Replace the jar in `plugins/` with `EcoSTG-1.5.11.jar` and **restart**.
