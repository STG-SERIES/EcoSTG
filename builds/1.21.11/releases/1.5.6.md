# EcoSTG 1.5.6

**Jar:** `build/libs/EcoSTG-1.5.6.jar`  
**Requires:** Paper 1.21.11+, Java 21

## What's updated

### Homes
- Removed the chest-style homes list and icon picker.
- Homes are dialog buttons again, colored by the home's color.
- **Change Color** offers presets (Aqua, White, Red, Orange, Yellow, Green, Blue, Purple, Pink, Gray) plus a custom **HEX** field (`#RRGGBB`).
- Default color is Aqua (`#55FFFF`). Old item-icon values reset to that default.
- Existing homes and names are kept.

## Install

Replace the jar in `plugins/` with `EcoSTG-1.5.6.jar` and **restart**.
