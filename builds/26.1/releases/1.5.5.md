# EcoSTG 1.5.5

**Jar:** `build/libs/EcoSTG-1.5.5.jar`  
**Requires:** Paper 1.21.11+, Java 21

## What's updated

### Homes
- The homes list is a chest so each home is its **item icon + name** (for example a bed named `Home`).
- Click a home to open Teleport / Change Icon / Rename / Delete.
- Dialogs cannot put a real item on a button; this keeps the correct textures.

## Install

Replace the jar in `plugins/` with `EcoSTG-1.5.5.jar` and **restart**.
