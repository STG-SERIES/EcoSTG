# EcoSTG 1.5.1

**Jar:** `build/libs/EcoSTG-1.5.1.jar`  
**Requires:** Paper 1.21.11+, Java 21

## What's updated

### Icons
- Home buttons, the icon picker, friends, stats, and pay now show item/player icons on the buttons (same style as the in-game item sprite).
- Home and profile body items are larger and include decorations so the icon actually appears.

## Install

Replace the jar in `plugins/` with `EcoSTG-1.5.1.jar` and **restart**. Homes are unchanged.
