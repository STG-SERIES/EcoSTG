# EcoSTG 1.5.16

**Jar:** `build/libs/EcoSTG-1.5.16.jar`  
**Requires:** Paper or Purpur 1.21.11+, Java 21

## Changes

- Homes list shows **all homes** (removed Show More / paging).
- Home detail: color control is an **ender pearl icon** button (opens the color picker).

## Upgrade

Replace the jar with `EcoSTG-1.5.16.jar` and **restart**.
