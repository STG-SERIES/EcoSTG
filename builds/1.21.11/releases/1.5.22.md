# EcoSTG 1.5.22

**Jars:** `builds/<platform>/EcoSTG-1.5.22.jar`  
**Platforms:** Paper **1.21.11** (Java 21+), **26.1** / **26.1.2** / **26.2** / **26.3** (Java 25+)

## Changes

- **Combat mode:** hitting a player or taking any damage starts an action-bar timer (`Combat: <blue>Ns</blue>`).
- While tagged, home / TPA / TPAHere / RTP are blocked. Damage again resets the countdown.
- Operators are never tagged; the other player in a fight with an OP still is.
- Config: `combat.duration-seconds` (default `15`).
- Multi-platform builds: separate jars under `builds/` for 1.21.11, 26.1, 26.1.2, 26.2, and 26.3.

## Upgrade

Replace the jar with the matching `builds/<platform>/EcoSTG-1.5.22.jar` and **restart**. Existing `config.yml` keeps old keys; add `combat.duration-seconds` if you want a non-default value.
