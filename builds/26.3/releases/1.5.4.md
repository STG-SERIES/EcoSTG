# EcoSTG 1.5.4

**Jar:** `build/libs/EcoSTG-1.5.4.jar`  
**Requires:** Paper 1.21.11+, Java 21

## What's updated

### Menus
- Dialogs size their button grid to the actual buttons, so leftover empty columns no longer pull rows to the left.
- A leftover last button stretches to the full row width.
- Item previews sit in the center (no side description pulling them left).
- Back/Close matches the row width.
- Choose Icon centers leftover items in the chest.

## Install

Replace the jar in `plugins/` with `EcoSTG-1.5.4.jar` and **restart**.
