# EcoSTG 1.5.8

**Jar:** `build/libs/EcoSTG-1.5.8.jar`  
**Requires:** Paper 1.21.11+, Java 21

## What's updated

### Gamemode (OP only)
- ESC pause button opens the **runtime hub** (`Open hub`), so **Gamemode** appears for operators only and stays hidden for everyone else.
- `/menu` already behaved this way.

### Leaderboards
- Pages match the ranked list style: player heads, `#1` gold / `#3` bronze, `Name - value`.
- Titles use **Top …** (e.g. Top Playtime).
- Playtime shows days when long enough (`502d 13h`).

### Profile description
- Players can set a short bio in the **GUI** (Settings → Description, or Edit Description on their own stats / friend profile).
- Others see it on stats and friend profiles.
- Max 120 characters; Clear removes it.

## Install

Replace the jar in `plugins/` with `EcoSTG-1.5.8.jar` and **restart**.
