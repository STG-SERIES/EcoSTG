# EcoSTG 1.5.14

**Jar:** `build/libs/EcoSTG-1.5.14.jar`  
**Requires:** Paper or Purpur 1.21.11+, Java 21

## Changes

- In-game notices use the **action bar** (text above the hotbar) instead of chat.
- No `[EcoSTG]` / branding prefix on notices.
- `/ecostg help` stays in chat as multi-line reference (title is just **Help**).
- TPA **[Accept] / [Deny]** clickable buttons remain in chat (required for clicks).

## Upgrade

Replace the jar with `EcoSTG-1.5.14.jar` and **restart**.
You can remove the unused `messages.prefix` key from `config.yml` if present.
