# EcoSTG 1.5.20

**Jar:** `build/libs/EcoSTG-1.5.20.jar`  
**Requires:** Paper or Purpur 1.21.11+, Java 21

## Changes

- Home **Choose Color** layout fixed (color grid, HEX field, Apply HEX, and Back share the same width).
- Removed the ender pearl icon from the home color button — label is **Color: …** only.

## Upgrade

Replace the jar with `EcoSTG-1.5.20.jar` and **restart**.
