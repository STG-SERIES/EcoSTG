# EcoSTG 1.5.12

**Jar:** `build/libs/EcoSTG-1.5.12.jar`  
**Requires:** Paper 1.21.11+, Java 21

## What's updated

### Compact prices everywhere
- All money displays use **K / M / B / T** (e.g. `$ 2.5K`, `$ 1.2M`).

### Worth prices (donut.auction-inspired)
- Retuned from [donut.auction](https://donut.auction/) market ratios (sampled popular items, others extrapolated).
- Scaled ~÷1000 so EcoSTG stays playable with a 500 starting balance.
- On first boot of 1.5.12, `worth.yml` is rewritten (`worth-version: 2`).

## Install

Replace the jar with `EcoSTG-1.5.12.jar` and **restart**.  
Optional: delete `plugins/EcoSTG/worth.yml` before restart if you want a clean file (the plugin also auto-rewrites on version bump).
