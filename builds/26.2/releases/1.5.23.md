# EcoSTG 1.5.23

**Jars:** `builds/1.21.11/EcoSTG-1.5.23.jar`, `builds/26.2/EcoSTG-1.5.23.jar`  
**Requires:** matching Paper line (1.21.11 → Java 21+; 26.2 → Java 25+)

## Changes

- Combat mode is **PvP only**: tagging requires damage from/to another player (melee, projectile, player TNT).
- Mobs, fall, fire, drowning, and other non-player damage no longer start combat.
- **Feature toggles** in `config.yml` → `features.*` (economy, auction, sell, pay, tpa, enderchest, homes, rtp, jobs, …).
  - `features.economy: false` also disables auction, sell, pay, balance, moneytop, and jobs.
  - With economy off, money is hidden from stats, leaderboards, Settings (Money Nametag / Money privacy), and below-name nametags.
  - Hub `/menu` updates on reload; **ESC pause buttons need a restart**.

## Upgrade

Replace the jar for your Paper line and **restart**. Merge new `features` / `messages.feature-disabled` keys into existing `config.yml` if needed.
