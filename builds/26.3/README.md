# EcoSTG for Paper 26.3

**Plugin version:** `1.5.22`  
**Jar:** `EcoSTG-1.5.22-paper26.3.jar`  
**Paper API:** `26.3.build.181-stable`  
**Java:** 25+

## Install

1. Use a **Paper/Purpur 26.3** server (Java 25+)
2. Put `EcoSTG-1.5.22-paper26.3.jar` in `plugins/`
3. Restart the server

Release notes: see `releases/` in this folder (same notes as the main repo).

Do **not** mix jars across Paper major lines (e.g. do not put the 1.21.11 jar on a 26.x server).
