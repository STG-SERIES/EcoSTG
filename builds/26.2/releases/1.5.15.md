# EcoSTG 1.5.15

**Jar:** `build/libs/EcoSTG-1.5.15.jar`  
**Requires:** Paper or Purpur 1.21.11+, Java 21

## Changes

- Removed **RTP Queue** / `/rtpq` entirely.
- **Settings** is always the last hub button (ESC + `/menu`).
- Settings toggles remade as tap-cycle buttons (no `[ON]` / `[OFF]`):
  - Chat / Notifications: red **Noone** → gold **Friends** → green **Everyone**
  - Instant TPA / TPAHere: same colors
  - Visuals / General / Privacy: colored **On** / **Off** or **Everyone** / **Hidden**
- Profile **Description** renamed to **Bio** everywhere in the UI.

## Upgrade

Replace the jar with `EcoSTG-1.5.15.jar` and **restart**.
